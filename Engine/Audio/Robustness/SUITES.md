All files 16 kHz mono PCM16, generated by `Fixtures/tools/gen_fixtures.py` (see `Fixtures/audio/README.md`).

| Suite | Dir | Condition | Lab use |

Engine-level metrics (`Tests/EngineTests/RobustnessTests.swift`):
- `SNREstimate.percentileSNR` before/after `SpectralGateNoiseSuppressor` must improve on every noisy file.
- `SpectralGateNoiseSuppressor` compute < 20 ms per 100 ms chunk.
- Bluetooth mode classification on mocked `AudioDeviceInfo`.

WER delta with/without NS is a Lab-level measurement (needs the ASR model on disk): run the harness on
`noisy` with `RobustnessProfile.raw` vs `.default` once P1.3's engine is wired through `AcousticCaptureSource`.
